# Parte 01 — Camadas de efeito no HTML

Os efeitos visuais usam divs fixos que ficam em cima de toda a página. Eles precisam ser os primeiros elementos dentro de <body> — antes de qualquer conteúdo.
01
CRT Overlay — Scanlines & Vignette

Um div vazio que fica fixo sobre toda a tela. O visual vem do CSS.

📄 index.html
↓ encontre esta linha
  <body>
+ adicione logo depois
  <body>
    <div class="crt-overlay"></div>
O que é: Um div que cobre toda a tela (via CSS: position: fixed, inset: 0). Ele não tem conteúdo próprio — os efeitos visuais vêm de ::before (scanlines) e ::after (vignette), que adicionaremos no CSS em seguida. pointer-events: none faz os cliques passarem por ele.
02
Noise — Div para o ruído estático

Elemento onde o JavaScript vai inserir a textura de noise via Canvas.

📄 index.html
↓ encontre esta linha (que você acabou de adicionar)
    <div class="crt-overlay"></div>
+ adicione na linha seguinte
    <div class="crt-overlay"></div>
    <div class="noise" id="noise"></div>
O que é: Mais um div fixo, vazio agora. O id="noise" é para o JavaScript conseguir achar ele depois via getElementById('noise') e injetar a textura de pixels aleatórios como background-image.
03
Scroll Progress — Barra de progresso

Linha fina no topo que cresce conforme a página é rolada.

📄 index.html
↓ encontre
    <div class="noise" id="noise"></div>
+ adicione na linha seguinte
    <div class="noise" id="noise"></div>
    <div class="scroll-progress" id="scrollProgress"></div>
O que é: Um div fixo no topo da tela, com width: 0% inicialmente. O JavaScript vai aumentando o width de 0% a 100% conforme você rola a página.
04
Ambient Glow — Luz azulada no topo

Gradiente radial sutil que emula o brilho difuso de um monitor.

📄 index.html
↓ encontre
    <div class="scroll-progress" id="scrollProgress"></div>
+ adicione na linha seguinte
    <div class="scroll-progress" id="scrollProgress"></div>
    <div class="ambient-glow"></div>
O que é: Um div fixo posicionado acima do topo da tela (top: -200px) com um gradiente radial azulado bem opaco (4%). Dá a sensação de luz emanando de cima da página sem chamar atenção. Não precisa de JavaScript — é CSS puro.
05
Boot Screen — Tela de inicialização

Overlay que cobre o site inteiro e exibe o texto de boot. Desaparece quando o JS termina de rodar.

📄 index.html
↓ encontre
    <div class="ambient-glow"></div>
+ adicione na linha seguinte
    <div class="ambient-glow"></div>

    <div class="boot-screen" id="bootScreen">
        <div class="boot-text" id="bootText"></div>
    </div>
O que é: Um div que cobre 100% da tela (position: fixed, z-index: 10000) com fundo preto. O .boot-text é onde o JavaScript vai injetando as linhas de texto uma por uma. Quando o boot termina, o JS adiciona a classe .hidden nele, que o faz desaparecer com uma transição de opacidade.
06
Main Wrapper — Envolver o conteúdo

Todo o site precisa ficar invisível durante o boot. Para isso, envolvemos tudo em um div que começa com opacity: 0.

📄 index.html
↓ encontre (após a boot-screen)
    </div> <!-- fim do boot-screen -->

    <!-- ¨¨HEADER -->
    <header>
+ envolva TODO o conteúdo neste div
    </div> <!-- fim do boot-screen -->

    <div class="main-wrapper" id="mainContent">

        <!-- ¨¨HEADER -->
        <header>...
        </header>

        <!-- nav, seções, footer... tudo aqui dentro -->

    </div> <!-- fim do main-wrapper -->
O que é: Um wrapper que engloba header, nav, todas as seções e o footer. No CSS, ele começa com opacity: 0. Quando o boot termina, o JS adiciona a classe .visible nele, que o anima para opacity: 1. Sem isso, o site apareceria junto com o boot.
07
fade-section — Marcar as seções para fade-in

Adicionar a classe em cada seção e no nav para que o IntersectionObserver as encontre.

📄 index.html
↓ encontre cada uma dessas tags
    <nav>

    <section id="arquetipo">
    <section id="pilares">
    <section id="atmosfera">
    ... todas as seções
+ adicione class="fade-section" em todas
    <nav class="fade-section">

    <section id="arquetipo" class="fade-section">
    <section id="pilares" class="fade-section">
    ... mesmo em todas as seções
O que é: Uma marcação para o JavaScript. No script, vamos usar querySelectorAll('.fade-section') para pegar todos esses elementos de uma vez e monitorá-los com o IntersectionObserver. Quando cada um entrar na tela, a classe .visible é adicionada e o CSS faz o fade-in.

CSS do CRT Overlay

Scanlines via repeating-linear-gradient e vignette via radial-gradient.

🎨 style.css
↓ encontre (depois do reset)
*::after {
  ...
}

/* ¨¨BASE DO DOCUMENTO */
html {
+ adicione entre o reset e o /* ¨¨BASE DO DOCUMENTO */
/* """CRT OVERLAY */
.crt-overlay {
    position: fixed;
    inset: 0;
    pointer-events: none;
    z-index: 9999;
}

.crt-overlay::before {
    content: '';
    position: absolute;
    inset: 0;
    background: repeating-linear-gradient(
        0deg,
        transparent,
        transparent 2px,
        rgba(0, 0, 0, 0.04) 2px,
        rgba(0, 0, 0, 0.04) 4px
    );
}

.crt-overlay::after {
    content: '';
    position: absolute;
    inset: 0;
    background: radial-gradient(
        ellipse at center,
        transparent 50%,
        rgba(0, 0, 0, 0.35) 100%
    );
}
::before cria as scanlines: um gradiente que repete a cada 4px (2px transparente + 2px preto a 4% de opacidade). ::after cria o vignette: um gradiente radial que vai de transparente no centro para preto nas bordas. inset: 0 é uma abreviação para top:0; right:0; bottom:0; left:0.

CSS das Animações — @keyframes + fade-section

Flicker no h1, cursor piscando, e as seções surgindo no scroll.

🎨 style.css
↓ encontre (o h1 que você já tem)
h1 {
    font-family: 'Space Mono', monospace;
    font-size: clamp(1.6rem, 4vw, 2.4rem);
    ...
}
+ adicione a animation no h1 existente, e os @keyframes antes dele
/* """ANIMAÇÕES */
@keyframes subtle-flicker {
    0%, 100% { opacity: 1; }
    92%       { opacity: 1; }
    93%       { opacity: 0.88; }
    94%       { opacity: 1; }
    95%       { opacity: 0.92; }
    96%       { opacity: 1; }
}

@keyframes blink {
    0%, 100% { opacity: 1; }
    50%       { opacity: 0; }
}

.cursor-blink {
    animation: blink 0.7s steps(1) infinite;
}

/* Adicione a linha de animation no h1 que já existe */
h1 {
    ...seus estilos existentes...
    animation: subtle-flicker 4s ease-in-out infinite;
}

/* """FADE-IN NO SCROLL */
.fade-section {
    opacity: 0;
    transform: translateY(12px);
    transition: opacity 0.6s ease, transform 0.6s ease;
}

.fade-section.visible {
    opacity: 1;
    transform: translateY(0);
}
subtle-flicker: de 0% a 91% fica estável em opacity 1. Entre 92% e 96% (num ciclo de 4s = cerca de 0.16s) a opacidade cai levemente duas vezes. Praticamente imperceptível — é o que torna o efeito bom. blink com steps(1): steps(1) remove a suavização — o cursor vai de 100% para 0% sem transição, como um cursor real de terminal. fade-section: começa deslocado 12px pra baixo e invisível. Quando o JS adiciona .visible, volta para a posição normal com fade.

# Parte 03 — JavaScript

Abra o script.js. Ele está vazio agora. Vamos adicionar os 4 sistemas em ordem. Cada bloco vai após o anterior — sem nada entre eles além dos comentários.
12
JS — Noise Generator (Canvas API)

Primeiro bloco do script.js. Gera pixels aleatórios e os aplica como background.

⚡ script.js
+ escreva no início do arquivo
// """NOISE — ruído estático via Canvas API

const noiseEl = document.getElementById('noise');

const noiseCanvas = document.createElement('canvas');
noiseCanvas.width  = 256;
noiseCanvas.height = 256;
const noiseCtx = noiseCanvas.getContext('2d');

function generateNoise() {
    const imageData = noiseCtx.createImageData(256, 256);
    const data = imageData.data;

    for (let i = 0; i < data.length; i += 4) {
        const v    = Math.random() * 255;
        data[i]     = v;   // R
        data[i + 1] = v;   // G
        data[i + 2] = v;   // B
        data[i + 3] = 255; // Alpha
    }

    noiseCtx.putImageData(imageData, 0, 0);
    noiseEl.style.backgroundImage = `url(${noiseCanvas.toDataURL()})`;
    noiseEl.style.backgroundRepeat = 'repeat';
}

generateNoise();
setInterval(generateNoise, 120);
createElement('canvas'): cria um canvas fora do HTML — só existe na memória. createImageData: cria um buffer de 256×256 pixels. Cada pixel são 4 posições no array (R, G, B, Alpha). Ao definir R=G=B com o mesmo valor aleatório, cada pixel fica numa tonalidade de cinza diferente. putImageData: escreve os pixels no canvas. toDataURL(): converte o canvas numa string base64 (data:image/png;base64,...) que serve como URL de imagem. setInterval(fn, 120): executa a função a cada 120ms — cria o efeito de noise "vivo".

JS — Boot Sequence (async/await)

Segundo bloco. Exibe linhas de texto uma por uma com delays, depois revela o site.

⚡ script.js

// """BOOT SEQUENCE

const bootLines = [
    { text: 'BIOS v2.04 — POST check OK',         delay: 80  },
    { text: 'Memory: 512MB SDRAM ... verified',    delay: 60  },
    { text: 'IDE0: WDC WD800JB-00JJA0 (80GB)',     delay: 70  },
    { text: 'Loading GRUB...',                    delay: 200 },
    { text: '',                                   delay: 100 },
    { text: ':: Arch Linux (kernel 2.6.32-arch)',  delay: 150 },
    { text: '   [OK] net.eth0',                    delay: 60  },
    { text: '   [OK] sound.alsa',                  delay: 50  },
    { text: '   [OK] daemon.sshd',                 delay: 50  },
    { text: '',                                   delay: 80  },
    { text: 'login: architect',                   delay: 300 },
    { text: 'password: ********',                 delay: 200 },
    { text: '',                                   delay: 100 },
    { text: '$ cat /etc/motd',                    delay: 200 },
    { text: '',                                   delay: 80  },
    { text: '  "Close the world, open the nExt."', delay: 150 },
    { text: '',                                   delay: 100 },
    { text: '$ startx --manifest',                delay: 400 },
];

const bootText    = document.getElementById('bootText');
const bootScreen  = document.getElementById('bootScreen');
const mainContent = document.getElementById('mainContent');

async function runBoot() {
    let fullText = '';

    for (const line of bootLines) {
        fullText += line.text + '\n';
        bootText.innerHTML =
            fullText + '<span class="cursor-blink">█</span>';

        await new Promise(r => setTimeout(r, line.delay));
    }

    await new Promise(r => setTimeout(r, 500));

    bootScreen.classList.add('hidden');
    mainContent.classList.add('visible');
}

runBoot();
bootLines: array de objetos com o texto e o delay de cada linha. O delay variado cria o efeito de tempo real. async function: marca a função para poder usar await. await new Promise(r => setTimeout(r, ms)): pausa a execução por ms milissegundos sem travar o browser — é o "sleep" do JavaScript. innerHTML: injeta HTML direto no elemento — por isso o cursor com <span class="cursor-blink"> funciona. classList.add('hidden'): adiciona a classe que vai apagar o boot via CSS. classList.add('visible'): adiciona a classe que vai revelar o site.
14
JS — Scroll Progress

Terceiro bloco. Calcula quantos % da página foram rolados e atualiza a largura da barra.

⚡ script.js
+ adicione após a boot sequence
// """SCROLL PROGRESS

window.addEventListener('scroll', () => {
    const scrollTop    = document.documentElement.scrollTop;
    const scrollHeight =
        document.documentElement.scrollHeight - window.innerHeight;
    const progress = (scrollTop / scrollHeight) * 100;

    document.getElementById('scrollProgress').style.width =
        progress + '%';
});
scrollTop: quantos pixels já foram rolados desde o topo. scrollHeight - innerHeight: a altura total rolável (total do documento menos o que aparece na tela). Se não subtrair innerHeight, a barra nunca chega a 100% porque quando o final da página aparece, o scrollTop ainda não atingiu o scrollHeight completo. * 100: converte a fração para porcentagem. style.width: atualiza a largura do div diretamente via JavaScript — o CSS transition: width 0.1s que colocamos antes suaviza o movimento.
15
JS — IntersectionObserver (Fade-in)

Quarto e último bloco. Monitora as seções e adiciona .visible quando entram na tela.

⚡ script.js
+ adicione ao final do arquivo
// """FADE-IN NO SCROLL — IntersectionObserver

const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            entry.target.classList.add('visible');
        }
    });
}, { threshold: 0.1 });

document.querySelectorAll('.fade-section')
    .forEach(el => observer.observe(el));
IntersectionObserver: uma API que avisa quando um elemento entra ou sai da viewport — muito mais eficiente que escutar o evento scroll e calcular posições manualmente. threshold: 0.1: dispara quando 10% do elemento fica visível na tela. entry.isIntersecting: booleano — true se o elemento está visível, false se saiu. classList.add('visible'): adiciona a classe que o CSS usa para fazer o fade-in (opacity: 1, transform: translateY(0)). querySelectorAll + forEach: seleciona todos os .fade-section de uma vez e registra cada um no observer.
